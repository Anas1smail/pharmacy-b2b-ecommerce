## 📌 Project Overview
This platform is a comprehensive B2B e-commerce solution engineered to bridge the supply chain between pharmacies and wholesale warehouses. Developed over a 5-month period, it optimizes bulk ordering, real-time inventory synchronization, and secure transaction workflows through a mobile client and a dedicated web dashboard.

## 🛠 Technical Architecture & Stack
This project is built with a focus on scalable architecture, clean code principles, and intelligent automation.

* **Mobile Application (Pharmacy Client):** Flutter 
  * *Architecture:* MVVM (Model-View-ViewModel)
  * *State Management:* Riverpod
* **Web Dashboard (Warehouse Portal):** React.js
* **Backend & Database:** Django , PostgreSQL
* **Artificial Intelligence:** Integrated Computer Vision model for automated Pharmacy ID card scanning and verification.

## 🚀 Key Features
* **AI-Powered Onboarding:** Utilizes Computer Vision to instantly scan, extract, and verify data from Pharmacy ID cards, streamlining the secure registration process.
* **Warehouse Management Dashboard:** A dedicated React.js portal allowing warehouse managers to process orders, manage stock, and track analytics in real-time.
* **Seamless B2B Ordering:** Custom mobile workflows designed specifically for wholesale pharmacy restocks, including multi-warehouse price comparisons and intelligent cart management.
* **Robust State Management:** Implemented Riverpod within a strict MVVM architecture to ensure predictable UI states, efficient caching, and highly maintainable code.
